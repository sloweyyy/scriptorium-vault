# Export Dashboard as PDF

## Overview
Workspace admins can export their current dashboard view as a PDF file directly from the dashboard toolbar. This feature generates and downloads a point-in-time snapshot of the dashboard. It enables you to easily share dashboard data outside of the platform, such as in an email or a status report.

## Prerequisites
* Workspace admin role permissions

## Steps
1. Navigate to the dashboard.
2. Click the export button on the dashboard toolbar.
   *Note: Large dashboards can take a few seconds to generate. The download starts automatically once ready.*

## FAQ
**Who can export the dashboard view?**
Only workspace admins can export the dashboard view as a PDF.

**What is the exported PDF used for?**
The PDF serves as a point-in-time snapshot of the dashboard, which you can share outside the product in resources like emails or status reports.
